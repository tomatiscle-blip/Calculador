# Reglas para agentes IA

## Antes de modificar código

1. Leer README.md.
2. Leer ARQUITECTURA.md.
3. Si el cambio afecta la GUI, leer INTERFAZ.md.

## Reglas del proyecto

- Un dato -> un lugar.
- Una cuenta -> un lugar.
- No duplicar lógica existente.
- No crear versiones paralelas de componentes.
- La GUI no implementa cálculos.
- La lógica vive en calc/.
- Los datos viven en datos/ u Obras/.

## Prioridad de documentación

README.md
ARQUITECTURA.md
INTERFAZ.md
PUESTA_EN_MARCHA.md

## Antes de crear algo nuevo

- Buscar si ya existe.
- Reutilizar si es posible.
- Integrar antes de duplicar.

## Antes de finalizar

Informar:
- archivos modificados,
- clases modificadas,
- métodos modificados.

## Entorno de ejecución

Proyecto desarrollado en Windows.

Terminal habitual: CMD.

Evitar comandos Linux/macOS:

- ls
- ls -la
- pwd
- head
- grep
- rm

Preferir:

- dir
- cd
- more
- findstr
- del
